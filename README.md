# MLD · ملاذ

منصة مجتمع عربية RTL مرتبطة بـ Discord، بواجهة وردية/بنفسجية متجاوبة، وحسابات وقاعدة بيانات PostgreSQL وخدمات Railway منفصلة للموقع وAPI والبوت.

## الخدمات
- **Web:** الصفحة الرئيسية والتنقل والوحدات التفاعلية.
- **API:** حسابات باسم مستخدم وكلمة مرور، تحقق عضوية Discord، رسائل عامة وخاصة، تذاكر وتقديمات وآراء وقروبات، لوحة إدارة، غرف سينما، منصة بوتات، نقاط وترتيب.
- **Bot:** بوت المجتمع ومشغّل البوتات المحفوظة والمشفرة في قاعدة البيانات.

## الألعاب المتصلة
- أونو، لودو، روليت، كود نيمز، مافيا، ومونوبولي لها حالات لعب محفوظة في PostgreSQL.
- جاكارو وبلوت ومقوسر ما زالت بحاجة إلى محركات لعب كاملة؛ لا تعتبر جاهزة لمجرد ظهورها في قائمة الألعاب.

## متغيرات البيئة الأساسية
`DATABASE_URL`, `JWT_SECRET`, `DISCORD_TOKEN` أو `DISCORD_BOT_TOKEN`, `DISCORD_GUILD_ID`, `BOT_TOKEN_ENCRYPTION_KEY`.
لا تضع التوكنات أو كلمات المرور في الملفات أو مستودع GitHub.

## التحقق
فحوصات تركيب JavaScript تتم قبل النشر، ويجب أن يظل اختبار التفاعل الحقيقي للحسابات وDiscord والبوتات والألعاب جزءاً من التحقق النهائي؛ نجاح نشر Railway وحده لا يثبت أن كل مسار يعمل دون أخطاء.

الشعار الأصلي محفوظ كما هو في `web/public/logo.svg.JPG`.
