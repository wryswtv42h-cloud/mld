# MLD · Malaz

واجهة جديدة لمجتمع ملاذ بهوية وردية وبنفسجية مستوحاة من الشعار، وتصميم عربي RTL متجاوب مع الهاتف والكمبيوتر.

## التشغيل
- يتطلب Node.js 20 أو أحدث.
- شغّل `npm start` ثم افتح المنفذ 3000.
- على Railway استخدم جذر المستودع كـ Root Directory وأمر التشغيل `npm start`.

## تنبيه
هذه النسخة واجهة وتجربة تنقل أمامية. تسجيل الحسابات وقاعدة البيانات والألعاب المتصلة والزاجل وربط Discord ولوحة إدارة البوتات تحتاج خدمات خلفية وإعدادات آمنة قبل تفعيلها. لا توجد أسرار أو توكنات ضمن المستودع.

الشعار الأصلي محفوظ كما هو في `web/public/logo.svg.JPG`.
