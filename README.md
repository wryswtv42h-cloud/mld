# MLD | ملاذ

منصة متكاملة — بوتات ديسكورد + ألعاب جماعية + موقع.

## الحقوق
- **المالك:** MLD
- **المطور:** فهد المطيري
- **الديسكورد:** w4px

## الهيكل
- `api/` — الخادم الخلفي (Express + PostgreSQL + Socket.IO)
- `web/` — الموقع (HTML + CSS + JS)

## المميزات
- تسجيل دخول (يوزر/باسورد)
- بروفايل + أفاتار
- شات عام (Socket.IO)
- الزاجل (رسائل سرية)
- منصة بوتات (كل مستخدم يضيف بوت)
- ألعاب جماعية:
  - أونو
  - جاكارو
  - كود نيمز
  - بالوت
  - لودو
  - مونوبولي
  - مقوصر
- نظام جلسات (مشاهدين + بوتات)
